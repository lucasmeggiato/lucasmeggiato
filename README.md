## Sobre mim

Sou um desenvolvedor em formação no Brasil, construindo projetos web e consolidando fundamentos de programação. Meu portfólio reúne interfaces responsivas, aplicações em JavaScript no navegador, estudos de Programação Orientada a Objetos e exercícios em Python.

- Transformo conceitos estudados em projetos navegáveis e publicados.
- Pratico organização de interfaces, manipulação do DOM e persistência de dados.
- Busco evoluir em qualidade de código, testes, acessibilidade e documentação.
- Valorizo soluções claras, úteis e fáceis de manter.

## Projetos em destaque

<details open>
<summary><strong>Organizador de Tarefas - painel de registros operacionais</strong></summary>

Painel web para registrar e acompanhar tarefas e ocorrências com prioridade, status e contexto operacional.

| Aspecto | Detalhes |
| --- | --- |
| Stack | HTML, CSS, JavaScript e Supabase |
| Recursos | Cadastro, edição, conclusão, reabertura, exclusão, busca, filtros, ordenação e estatísticas |
| Dados | Persistência no Supabase e atualização em tempo real |
| Experiência | Interface responsiva, confirmações, notificações e versão para impressão |
| Publicação | Vercel |
| Links | [Repositório](https://github.com/lucasmeggiato/Organizador-tarefas) - [Demonstração](https://organizador-tarefas-one.vercel.app) |

</details>

<details>
<summary><strong>Guias de Arquitetura de Computadores - portal educacional</strong></summary>

Portal estático de estudo sobre história da computação, sistemas de numeração, arquiteturas de hardware e componentes computacionais.

| Aspecto | Detalhes |
| --- | --- |
| Stack | HTML e CSS incorporado |
| Escopo | Página inicial e 20 páginas temáticas |
| Conteúdo | Guias, exercícios, avaliações respondidas e análises técnicas |
| Experiência | Navegação responsiva e estilos preparados para impressão |
| Publicação | GitHub Pages |
| Links | [Repositório](https://github.com/lucasmeggiato/Trabalho-Arquitetura-e-Organizacao-de-Computadores) - [Demonstração](https://lucasmeggiato.github.io/Trabalho-Arquitetura-e-Organizacao-de-Computadores/) |

O projeto demonstra organização de grande volume de conteúdo técnico em uma experiência web consistente e acessível por diferentes dispositivos.

</details>

<details>
<summary><strong>Fundamentos de POO - site educacional multipágina</strong></summary>

Site que apresenta objetos e os quatro pilares da Programação Orientada a Objetos por meio de explicações e exemplos de código.

| Aspecto | Detalhes |
| --- | --- |
| Stack | HTML, CSS e JavaScript |
| Escopo | Cinco páginas conectadas por navegação temática |
| Conteúdo | Encapsulamento, herança, polimorfismo e abstração |
| Experiência | Cards, blocos de código, navegação ativa e adaptação para telas menores |
| Status | Projeto acadêmico em evolução |
| Link | [Repositório](https://github.com/lucasmeggiato/Trabalho-POO) |

O projeto transforma fundamentos de software em conteúdo visual estruturado, reforçando tanto o aprendizado técnico quanto a comunicação de conceitos.

</details>

<details>
<summary><strong>Trattoria Bella - protótipo de experiência web</strong></summary>

Protótipo navegável de restaurante com landing page, catálogo, detalhes de pratos e fluxo visual de carrinho.

| Aspecto | Detalhes |
| --- | --- |
| Stack | HTML e CSS |
| Escopo | Home, cardápio, páginas de produtos, login visual e estados de carrinho |
| Interface | Identidade visual consistente, grids e adaptação para telas menores |
| Status | Protótipo front-end sem autenticação, persistência ou pagamento |
| Publicação | GitHub Pages |
| Links | [Repositório](https://github.com/lucasmeggiato/Trabalho-oficina) - [Demonstração](https://lucasmeggiato.github.io/Trabalho-oficina/) |

O projeto explora hierarquia visual, navegação e construção de um fluxo de produto por meio de páginas estáticas conectadas.

</details>
